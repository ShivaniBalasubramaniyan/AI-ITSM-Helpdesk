## Overview
All corporate endpoints enforce Least Privilege Security. Standard user accounts do not hold permanent local Administrator privileges. All enterprise and developer software must be provisioned through approved channels.

## Approved Pre-Packaged Software (Self-Service)
The following approved applications require zero IT approval and can be installed immediately via **Company Portal** (Windows) or **Self Service** (macOS):
- Google Chrome, Mozilla Firefox Enterprise
- Slack Desktop, Zoom, Microsoft Teams
- Visual Studio Code, Git, Node.js LTS, Python 3.11
- Postman (Free Tier), Notepad++, 7-Zip

### How to Install from Company Portal
1. Click the Windows Start menu and search for **Company Portal**.
2. Select **Apps** in the left sidebar.
3. Search for the desired software and click **Install**.
4. The deployment will execute silently via Microsoft Intune in the background.

## Licensed & Developer Software Requests (Requires Approval)
Tools that require commercial licenses or elevated kernel permissions (e.g., Docker Desktop, JetBrains All Products Pack / PyCharm Professional, Adobe Creative Cloud, Tableau Desktop):
1. Submit an ITSM Software Provisioning ticket.
2. Select your Department Cost Center code.
3. Attach written manager approval or tag your manager as approver.
4. Turnaround SLA: 8 business hours upon approval.
